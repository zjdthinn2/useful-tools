# Useful Tools

按使用场景分的 33 个好用开源工具，大部分都能在 GitHub 上找到。括号里是仓库地址。

## 日常效率（8 个）

1. [PowerToys](https://github.com/microsoft/PowerToys) — 微软官方工具集，取色、批量改名、窗口分区、快速启动等。
2. [FlowLauncher](https://github.com/Flow-Launcher/FlowLauncher) — 按快捷键弹出搜索框，打开软件、找文件、算式。
3. [LocalSend](https://github.com/localsend/localsend) — 手机和电脑局域网互传，不经过任何网盘。
4. [ShareX](https://github.com/ShareX/ShareX) — 截图、录屏、做 GIF，还能截长图和识别文字。
5. [NanaZip](https://github.com/M2Team/NanaZip) — 7-Zip 的改进版，能用上 Win11 的右键菜单。
6. [Scoop](https://github.com/ScoopInstaller/Scoop) — 命令行装软件，一行命令装好、一行命令更新。
7. [Windows Terminal](https://github.com/microsoft/terminal) — 好用的终端，SSH 连 VPS 时比自带的顺手。
8. [Czkawka](https://github.com/qarmin/czkawka) — 找重复文件、相似图片和空文件夹，清理硬盘用。

## 系统与备份（3 个）

9. [Ventoy](https://github.com/ventoy/Ventoy) — 万能启动盘，往 256G U 盘里放 ISO 就能装系统。
10. [Rufus](https://github.com/pbatard/rufus) — 做单一系统启动盘，Ventoy 不能用的情况备选。
11. [Syncthing](https://github.com/syncthing/syncthing) — 电脑和手机的文件夹自动同步，不经过任何网盘。

## 账号安全（3 个）

12. [Bitwarden](https://github.com/bitwarden/clients) — 密码管理器，方便跨平台推荐的首选。
13. [KeePassXC](https://github.com/keepassxreboot/keepassxc) — 完全离线的密码管理器，适合不想把密码放在云端的时候。
14. [Aegis](https://github.com/beemdevelopment/Aegis) — 安卓上的两步验证 App，开源，可以加密备份。

## 安卓（2 个）

15. [Obtainium](https://github.com/ImranR98/Obtainium) — 直接从 GitHub 的发布页安装和更新 App，不用再去镜像站找安装包。
16. [Seal](https://github.com/JunkFood02/Seal) — 视频和音频下载工具。

## 做游戏与美术（7 个）

17. [Godot](https://github.com/godotengine/godot) — 游戏引擎。
18. [awesome-godot](https://github.com/godotengine/awesome-godot) — Godot 插件、模板和教程的合集。
19. [Pixelorama](https://github.com/Orama-Interactive/Pixelorama) — 免费的像素画软件，本身就是用 Godot 做的。
20. [LibreSprite](https://github.com/LibreSprite/LibreSprite) — Aseprite 早期开源版本的分支，免费，做像素动画。
21. [Tiled](https://github.com/mapeditor/tiled) — 瓦片地图编辑器，做 2D 游戏和灰渡的地图用。
22. [Krita](https://github.com/KDE/krita) — 免费的绘画软件，学画画够用。
23. [Blender](https://github.com/blender/blender) — 3D 建模。

## 学习与编程（5 个）

24. [GitHub Desktop](https://github.com/desktop/desktop) — 图形界面的 Git，给旧梦祷歌做版本管理最容易上手。
25. [VS Code](https://github.com/microsoft/vscode) — 写代码、改配置文件、看 Markdown 都行。
26. [hello-algo](https://github.com/krahets/hello-algo) — 中文的图解数据结构与算法，配动画，入门很好。
27. [CyberChef](https://github.com/gchq/CyberChef) — 英国情报机构开源的数据处理工具，编码转换、解密、格式转换都能做，CTF 必备。
28. [OpenCode](https://github.com/anomalyco/opencode) — 开源 MIT 的终端 AI 编程助手，不绑任何一家模型，能接 DeepSeek 等 75+ 家供应商和本地模型，支持装插件、自己改源码。

## 网络与代理（2 个）

29. [v2rayN](https://github.com/2dust/v2rayN) — 开源代理客户端，Windows、Linux、macOS 图形界面，支持 Xray、sing-box 等内核；Windows 64 位下 v2rayN-windows-64-desktop.zip（Avalonia 界面，解压即用），最新版 7.25.6（2026-10-11）。
30. [qBittorrent](https://github.com/qbittorrent/qBittorrent) — 开源免费无广告的 BT 下载客户端，Windows、Linux、macOS 都能用，支持磁力链、.torrent、RSS 订阅和搜索插件；Windows 64 位去官网 qbittorrent.org/download 下载，最新版 5.3.0（2026-10-19），默认 Qt6 + libtorrent 2.1.x，种子多、做种重的话选 lt12 版（libtorrent 1.2.x）。

## 工控安全（3 个）

31. [Wireshark](https://github.com/wireshark/wireshark) — 抓包分析，学 Modbus、S7 协议时离不开它。
32. [DVWA](https://github.com/digininja/DVWA) — 故意留了漏洞的练习网站，计划半小时攻破一把。
33. [OpenPLC](https://github.com/thiagoralves/OpenPLC_v3) — 开源的软 PLC，可以在电脑上搭工控仿真环境，正好接上阶段二。

## 几个使用习惯

- 从 Releases 下载：仓库右侧的 Releases 里有打好的安装包，不用自己编译。
- 看更新时间：项目最近一年还有更新，才说明有人维护。
- 认官方仓库：同名的 fork 和“汉化版”可能夹带东西，以 Star 最多、作者对得上的那个为准。
- Blender、Krita、Wireshark 在 GitHub 上是镜像，安装包最好去官网下载。

如果只装三款，我推荐 PowerToys、Bitwarden 和 GitHub Desktop，分别对应方法手册里的效率、账号和备份三块。
